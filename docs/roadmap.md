# Project Roadmap

## Phase 1 — Research Framework

- Define target roles
- Define company watchlist
- Create fit-scoring framework
- Build deep-research prompt
- Build recurring daily-search prompt
- Establish verification rules

## Phase 2 — Data Pipeline

- Build automated job collectors
- Normalize job data
- Detect duplicate listings
- Track job status changes
- Persist search history

## Phase 3 — Matching

- Compare job descriptions against candidate profile
- Calculate fit scores
- Rank opportunities
- Filter low-value applications

## Phase 4 — Application Intelligence

- Generate resume-tailoring recommendations
- Identify relevant hiring contacts
- Prepare LinkedIn outreach
- Prepare email outreach
- Recommend application sequence

## Phase 5 — Automation

- Schedule recurring searches
- Detect newly posted jobs
- Generate alerts for high-fit opportunities
- Maintain an application tracker
- Produce periodic search reports
