# Daily Workflow

## Deep Research Mode

Used when establishing or refreshing the broader opportunity landscape.

1. Load search criteria
2. Search priority companies
3. Discover new companies
4. Verify live job postings
5. Remove dead or duplicate listings
6. Score each opportunity
7. Prioritize strongest matches
8. Prepare application materials for top roles

## Daily Scout Mode

Used for recurring checks.

1. Search for newly posted roles
2. Compare against prior results
3. Ignore duplicates
4. Surface only strong new matches
5. Flag meaningful status changes
6. Prepare application-ready recommendations

## Application Mode

Triggered for APPLY NOW opportunities.

1. Analyze the complete job description
2. Compare against the candidate profile
3. Identify resume gaps
4. Recommend truthful resume changes
5. Identify the best relevant contact
6. Draft LinkedIn outreach
7. Draft email outreach
8. Recommend application and follow-up sequence
