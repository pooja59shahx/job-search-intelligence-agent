# Job Search Intelligence Agent

An AI-assisted internship research and application system designed to discover, verify, prioritize, and prepare high-fit opportunities.

## Goal

Reduce the time spent manually searching and applying for internships while improving the quality and relevance of each application.

The system is designed to:

- Discover newly posted internships
- Search target companies and discover new companies
- Verify that job opportunities are actually active
- Compare job descriptions against a candidate profile
- Score and prioritize opportunities based on fit
- Avoid repeatedly surfacing previously reviewed jobs
- Identify relevant hiring contacts
- Prepare personalized outreach
- Recommend truthful resume tailoring based on each job description

## Optimization Objective

The goal is not maximum application volume.

**Interview Probability × Role Quality × Full-Time Conversion Potential ÷ Time Required**
